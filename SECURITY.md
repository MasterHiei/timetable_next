# Security

Report a suspected vulnerability privately using the repository's GitHub Security → Report a vulnerability channel. If private reporting is unavailable, open an issue asking for a private contact without including exploit details. Do not post credentials or private application data.

Reports are handled on a best-effort basis with no response-time commitment. Include affected versions, a minimal reproduction and impact. Only the latest release line receives fixes. Confirmed exploitable vulnerabilities without mitigation block a new release. Dependency advisory checks are one input to review, not proof of absence of vulnerabilities.
