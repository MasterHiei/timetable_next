# Community conduct

Treat participants respectfully. Keep feedback about the work, accept good-faith questions, and avoid harassment, discrimination, threats, and disclosure of private information.

Maintainers may remove abusive content, restrict participation, or close discussions. For a private conduct report, use the maintainer contact on the repository owner's public profile; do not file conduct reports as security vulnerabilities. Reports are handled privately where practical. These expectations apply to this repository's issues, pull requests and discussions.
